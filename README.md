# 🛡️ PhishGuard Pro

An intelligent phishing website detection system that leverages Machine Learning to identify malicious URLs and protect users from phishing attacks.

---

## 📌 Overview

PhishGuard Pro is a cybersecurity-focused machine learning project that detects phishing websites by analyzing various URL and website-related features. The system classifies websites as **Legitimate** or **Phishing**, helping users avoid fraudulent websites that attempt to steal sensitive information such as passwords, banking credentials, and personal data.

This project demonstrates the application of data science and machine learning in solving real-world cybersecurity challenges through accurate phishing detection.

---

## ✨ Features

- 🔍 Real-time phishing URL detection

## 🚀 How It Works

1. User enters a website URL.
2. The application extracts important URL-based features.
3. The trained machine learning model processes these features.
4. The model predicts whether the website is:
   - ✅ Legitimate
   - 🚨 Phishing
5. The prediction is displayed to the user instantly.



